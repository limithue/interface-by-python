## 二、代码生成总体目标
基于原始三份源码（config.py、python接口.py、main.py）及《Python 端口扫描器问题分析》中列出的 15 项缺陷，生成升级后的可直接运行源码，满足以下核心指标：

1. 零第三方依赖：仅使用 Python 3.6+ 内置模块
2. Windows 普通权限 100% 可运行：ICMP 自动降级 TCP 探测，绝不跳过 IP
3. 扫 1-65535 不崩溃：ThreadPoolExecutor 线程池替代每端口一线程
4. 误报率可控：TCP 二次验证、UDP 保守策略
5. 合规内置：权限提示、大任务量确认、报告自动附加声明

## 三、逐文件生成指令

### 文件一：config.py（配置层）
#### 3.1.1 生成指令
生成全局配置模块，职责为集中管理所有常量、映射表与默认参数，禁止包含任何业务逻辑或 I/O 操作。

#### 3.1.2 必须包含的内容
| 配置项 | 类型 | 规格说明 |
|--------|------|----------|
| COMMON_PORTS | dict[int, str] | 端口到服务名的映射表，至少覆盖 28 种常见服务 |
| TCP_ALIVE_PORTS | list[int] | 降级存活探测轮询端口：[80, 443, 22, 3389, 445, 139, 21, 25] |
| DEFAULT_TIMEOUT | float | 单次探测超时，默认 1.0 秒 |
| DEFAULT_THREADS | int | 默认并发线程数，默认 10 |
| MAX_THREADS | int | 线程硬上限，固定 20 |
| COLORS | dict[str, str] | ANSI 颜色转义序列 |

#### 3.1.3 约束条件
- 所有键名必须为英文大写，符合常量命名规范
- 端口值必须在 1-65535 范围内
- 颜色代码必须为标准 \033[XXm 格式
- 文件内不得包含任何函数定义或执行逻辑

---

### 文件二：python接口.py（核心引擎层）
#### 3.2.1 生成指令
生成扫描核心引擎模块，职责为提供所有网络探测函数、存活检测逻辑与线程池扫描器类。必须保证线程安全、异常分层、权限兼容。

#### 3.2.2 必须实现的函数与类
| 名称 | 类型 | 功能规格 | 异常处理要求 |
|------|------|----------|--------------|
| colored(text, color) | 函数 | 跨平台彩色文本，Windows 自动启用 VT100 | 无异常 |
| _checksum(source_string) | 函数 | ICMP 报文校验和（RFC 1071） | 无异常 |
| scan_tcp_once | 函数 | 单次 TCP 全连接探测 | 捕获 socket.timeout、OSError 等 |
| scan_tcp | 函数 | TCP 扫描（含二次验证） | 依赖 scan_tcp_once |
| scan_udp | 函数 | UDP 保守探测 | 捕获 OSError、PermissionError |
| is_alive_icmp | 函数 | ICMP 存活探测，返回三级状态 | 捕获权限、超时异常 |
| is_alive_tcp | 函数 | TCP 降级探测，始终 return True | 单端口随机延迟 |
| is_alive | 函数 | 统一存活入口，自动降级 | 子函数处理异常 |
| PortScanner | 类 | 线程池扫描器 | 线程安全、支持中断 |

#### 3.2.3 PortScanner 类详细规格
- __init__：限制线程 1~20，初始化锁、停止事件、结果列表
- _worker：任务单元，支持中断，开放端口加锁写入，随机延迟
- start_scan：线程池调度，支持 Ctrl+C 取消任务，结果去重排序

#### 3.2.4 关键约束
- 禁止裸 except:，必须捕获具体异常
- 必须用 ThreadPoolExecutor，禁止每端口一线程
- 禁止跳过 IP，is_alive_tcp 必须 return True
- 仅使用内置模块，无第三方依赖

### 文件三：main.py（交互入口层）
#### 3.3.1 生成指令
生成交互入口模块，处理输入、调用扫描、输出结果、导出报告、合规提示。

#### 3.3.2 必须实现的函数
- parse_ip：支持 IP、域名、CIDR，限制网段大小
- parse_ports：支持 common、单端口、端口段，自动去重
- print_progress：原生进度条，无第三方库
- save_report：导出带时间戳的报告，附加合规声明
- check_admin：跨平台权限检测
- main：主流程，权限提示、输入、解析、扫描、展示、导出

#### 3.3.3 交互流程规格
启动 → 权限检测 → 输入目标/端口/协议 → 解析 → 大任务确认 → 扫描 → 展示结果 → 导出报告 → 合规提示

#### 3.3.4 界面输出规格
使用 ANSI 颜色：标题青色、权限黄/绿、错误红、开放绿、合规品红。

## 四、技术约束与规范
### 4.1 语言与环境约束
- Python 3.6+
- 零第三方库
- 仅使用白名单内置模块

### 4.2 代码风格约束
- 函数/变量：小写+下划线
- 类：大驼峰
- 常量：全大写
- 必须加 docstring 与注释

### 4.3 安全与合规约束

- 绝不跳过 IP
- 随机延迟防拦截
- 线程上限 20
- 禁止超大网段
- 报告自动附加合规声明
