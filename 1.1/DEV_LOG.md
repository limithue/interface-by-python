## 一、需求工程（Spec-First 规格优先）
### 1. 业务意图
基于《Python 端口扫描器问题分析》对原始工具进行系统性重构，解决 4 项致命缺陷、4 项功能缺陷、3 项并发安全问题及 4 项工程化缺陷，增强隐蔽性与合规性，输出可直接用于作业 / 项目交付的完整工程包（源码 + 文档）。

核心意图：构建一款**零第三方依赖、Windows 普通权限 100% 可运行、扫 1-65535 不崩溃、误报率可控**的授权内网端口扫描工具。

---

### 2. 功能性需求（结构化无歧义）
| 编号 | 需求项 | 规格说明 |
|------|--------|----------|
| FR-01 | 目标解析 | 支持单 IP、域名、CIDR 网段（如 192.168.1.0/24） |
| FR-02 | 端口支持 | common（28 种服务映射）、单端口、端口段（如 1-1000） |
| FR-03 | 协议扫描 | TCP 全连接扫描（含二次验证）、UDP 保守探测 |
| FR-04 | 存活预检 | ICMP Echo Request（管理员）自动降级 TCP 探测（普通权限） |
| FR-05 | 绝不跳过 | 存活检测失败时仍执行全端口扫描，禁止 continue 跳过 IP |
| FR-06 | 并发扫描 | ThreadPoolExecutor 线程池，1~20 线程可调，分批调度 |
| FR-07 | 结果输出 | ANSI 彩色控制台 + 可选 TXT 报告导出 |
| FR-08 | 服务映射 | 28 种常见端口自动匹配服务名 |
| FR-09 | 进度反馈 | 原生进度条，无第三方库 |
| FR-10 | 安全控制 | 大任务量二次确认、网段范围限制 |
| FR-11 | 中断处理 | Ctrl+C 安全退出，保留已扫描结果 |

### 5. BDD 行为规约（Given-When-Then）
#### 场景 1：C 段网段批量扫描
Given 用户输入目标 "192.168.1.0/24" 和端口 "common"
And 当前为管理员权限
When 执行 start_scan
Then 解析出 254 个主机地址
And 对每个存活主机扫描 28 个常见端口
And 返回所有开放端口列表
And 自动匹配服务名称

#### 场景 2：Windows 普通权限自动降级
Given 用户在 Windows 普通权限下运行工具
And 目标 IP 为 "192.168.1.1"
When 执行存活检测
Then ICMP 探测因 PermissionError 返回 None
And 自动降级为 TCP 探测
And 即使全部失败仍返回 True
And 继续执行全端口扫描

#### 场景 3：大端口段安全中断
Given 用户输入目标 "127.0.0.1" 和端口 "1-65535"
When 扫描中按下 Ctrl+C
Then 触发全局停止事件
Then 优雅关闭线程池
Then 展示已扫描结果
Then 安全退出不崩溃

#### 场景 4：扫描报告导出
Given 扫描完成且发现开放端口
When 用户选择保存报告
Then 生成带时间戳的 TXT 文件
And 文件包含完整结果与合规声明

## 二、架构设计（Architecture as Code）
### 1. 技术栈
| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 语言 | Python 3.6+ | 零第三方依赖 |
| 网络 | socket | TCP/UDP 基础能力 |
| 并发 | ThreadPoolExecutor | 线程池调度 |
| 网段 | ipaddress | CIDR 解析 |
| 权限 | ctypes / os | 管理员检测 |
| ICMP | raw socket | 标准 Echo 报文 |
| 输出 | ANSI 转义序列 | 彩色控制台 |

### 2. 架构模式
模块化三层架构：
- main.py：交互入口层
- python接口.py：核心引擎层
- config.py：配置层

### 3. 架构决策记录 ADR
#### ADR-001 线程模型：线程池替代手动线程
解决内存爆炸、崩溃问题，严格控制并发数。

#### ADR-002 存活检测：ICMP + TCP 自动降级
普通权限可运行，绝不漏扫禁 Ping 主机。

#### ADR-003 UDP 扫描：保守响应确认制
误报率接近 0，符合工业标准。

#### ADR-004 异常处理：分层捕获 + 独立中断通道
支持 Ctrl+C 安全退出，不闪退、不吞异常。

#### ADR-005 输出：彩色控制台 + 报告导出
提升可读性，支持交付存档。
