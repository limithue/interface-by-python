# 基于 Python 的 Windows 自用端口扫描工具

> **版本**: v2.0.0  
> **适用**: Windows 10/11, Python 3.8+  
> **用途**: 课程实训、自有局域网安全排查、授权测试环境  
> **合规**: 严格遵守《中华人民共和国网络安全法》

---

## 一、功能概述

本工具是一款基于 Python 标准库 + PyQt6 开发的轻量级端口扫描器，支持命令行与 GUI 双模式运行，具备以下核心功能：

| 功能模块 | 说明 |
|---------|------|
| **IP 解析** | 支持单 IP、IP 段（简写/全写）、CIDR 网段、域名、逗号分隔组合 |
| **端口解析** | 支持 `common`（16种常用端口）、`all`（全端口）、单端口、端口段、离散端口组合 |
| **扫描协议** | TCP 全连接扫描、**SYN 半连接扫描**（需管理员权限）、UDP 保守探测 |
| **存活预检** | ICMP ping 探测，无管理员权限自动降级为 TCP 探测 |
| **多线程调度** | 线程池并发控制（1~20 线程），支持暂停/恢复/停止 |
| **隐蔽扫描** | 随机发包间隔（0~5秒），降低防火墙拦截概率 |
| **结果导出** | TXT / CSV / JSON 三种格式，支持覆盖确认与元信息返回 |
| **配置持久化** | JSON 配置文件，自动保存/恢复窗口状态与扫描参数 |
| **日志记录** | 实时日志展示 + 文件持久化，支持 DEBUG/INFO/WARNING/ERROR 级别 |
| **结果着色** | GUI 表格按状态着色（绿色=开放、白色=关闭、黄色=过滤、红色=错误） |

## 二、安装与运行

### 2.1 环境要求

- **操作系统**: Windows 10/11（64位）
- **Python**: 3.8 及以上版本
- **依赖库**: PyQt6（仅 GUI 模式需要）

### 2.2 安装依赖

```bash
# 安装 PyQt6（GUI 界面必需）
pip install PyQt6

# 打包工具（可选）
pip install pyinstaller
```

### 2.3 运行方式

#### 方式一：GUI 模式（推荐）

```bash
python main.py --gui
# 或简写
python main.py -g
```

启动后弹出可视化界面，支持鼠标操作、实时进度、结果表格、日志查看。

#### 方式二：命令行模式

```bash
# 快速扫描（默认参数）
python main.py --target 192.168.1.1 --ports common --protocol tcp

# 完整参数示例
python main.py   --target 192.168.1.0/24   --ports 1-1000,3306,8080   --protocol syn   --threads 15   --timeout 2   --delay 1   --format csv   --output scan_report.csv
```

#### 方式三：交互式向导

不传入任何参数时，进入交互式向导模式：

```bash
python main.py
```

按提示逐步输入目标、端口、协议、线程数等参数。

## 三、参数说明

### 3.1 命令行参数

| 参数 | 简写 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--target` | `-T` | string | — | 目标 IP/域名，支持多种格式 |
| `--ports` | `-p` | string | `common` | 端口范围，支持 common/all/单端口/段/组合 |
| `--protocol` | `-P` | choice | `tcp` | 扫描协议：`tcp` / `udp` / `syn` |
| `--threads` | `-t` | int | `10` | 并发线程数（1~20） |
| `--timeout` | `-o` | int | `1` | 单次探测超时秒数（1~10） |
| `--delay` | `-d` | int | `0` | 随机延迟秒数（0~5），提升隐蔽性 |
| `--format` | `-f` | choice | `txt` | 导出格式：`txt` / `csv` / `json` |
| `--output` | `-O` | string | — | 输出文件路径 |
| `--gui` | `-g` | flag | — | 启动 GUI 模式 |
| `--no-compliance` | — | flag | — | 跳过合规提示（仅限自动化脚本） |

### 3.2 目标格式示例

| 输入格式 | 示例 | 说明 |
|---------|------|------|
| 单 IP | `192.168.1.1` | 扫描单个主机 |
| IP 段简写 | `192.168.1.1-10` | 扫描 192.168.1.1 到 192.168.1.10 |
| IP 段全写 | `192.168.1.1-192.168.2.10` | 支持跨网段（最多 256 个 IP） |
| CIDR | `192.168.1.0/24` | 网段扫描（前缀需 ≥ /16） |
| 域名 | `baidu.com` | 自动解析为 IP |
| 组合 | `192.168.1.1,10.0.0.0/30,example.com` | 逗号分隔，混合格式 |

### 3.3 端口格式示例

| 输入格式 | 示例 | 说明 |
|---------|------|------|
| 关键字 | `common` | 16 种常用端口（21,22,23,25,53,80,110,135,139,443,445,3306,3389,5432,6379,8080） |
| 全端口 | `all` | 1~65535（谨慎使用，任务量巨大） |
| 单端口 | `80` | 扫描单个端口 |
| 端口段 | `1-1000` | 扫描 1 到 1000 号端口 |
| 离散端口 | `22,80,443,3306` | 逗号分隔多个端口 |
| 混合 | `common,8080-8082,9000` | 组合使用 |

### 4.2 操作步骤

1. **输入目标**：在"目标IP"框输入 IP/域名（支持多种格式组合）
2. **输入端口**：在"端口"框输入端口范围（默认 `common`）
3. **选择协议**：下拉选择 TCP / UDP / SYN
4. **调整参数**：线程数（默认 10）、超时秒数、随机延迟
5. **勾选选项**："跳过离线IP"可在扫描前 ping 检测主机是否在线
6. **开始扫描**：点击"▶ 开始扫描"按钮
7. **查看结果**：结果表格实时更新，开放端口以绿色高亮显示
8. **导出报告**：扫描完成后点击导出按钮保存结果

### 4.3 快捷键与提示

- **暂停/恢复**：扫描过程中点击"⏸ 暂停"可暂停，再次点击恢复
- **终止扫描**：点击"⏹ 停止"立即终止当前扫描
- **配置记忆**：退出时自动保存当前参数，下次启动自动恢复
- **窗口恢复**：窗口大小和位置也会被保存

## 五、扫描协议对比

| 协议 | 原理 | 权限要求 | 隐蔽性 | 速度 | 适用场景 |
|------|------|---------|--------|------|---------|
| **TCP 全连接** | 完成三次握手 | 普通用户 | 低（日志记录） | 快 | 通用扫描，获取 Banner |
| **SYN 半连接** | 仅发 SYN 不建连 | **管理员** | **高** | 快 | 隐蔽探测，绕过部分 IDS |
| **UDP** | 发送空 UDP 包 | 普通用户 | 中 | 慢 | DNS/DHCP 等服务探测 |

### SYN 扫描技术说明

SYN 半连接扫描（Stealth Scan）是网络安全领域经典的隐蔽扫描技术：

- **原理**：发送 TCP SYN 包后，若收到 SYN+ACK 则判定端口开放，但不回复 ACK 完成握手，连接不建立
- **优势**：服务端不记录完整连接日志，隐蔽性高；不建立全连接，速度快
- **限制**：Windows 需管理员权限（Raw Socket 限制）；无法获取 Banner；可能被防火墙拦截 SYN 包
- **实现**：本工具手动构造 IP 头 + TCP 头（struct.pack），遵循 RFC 793/1071 标准

## 六、打包为 EXE

### 6.1 使用 PyInstaller 打包


### 6.2 打包参数说明

| 参数 | 说明 |
|------|------|
| `-F` | 打包为单个 EXE 文件（推荐） |
| `-w` | 无控制台窗口（GUI 模式使用） |
| `-i icon.ico` | 设置程序图标（可选） |

### 6.3 打包后文件

打包完成后，`dist/main.exe` 即为可执行文件，可在无 Python 环境的 Windows 电脑上直接运行。

## 九、常见问题

### Q1: 启动 GUI 时报错 "No module named 'PyQt6'"
**解决**: 安装 PyQt6：`pip install PyQt6`

### Q2: SYN 扫描提示 "需要管理员权限"
**解决**: 右键点击程序 → "以管理员身份运行"，或改用 TCP 全连接扫描

### Q3: 扫描结果全部为 FILTERED
**解决**: 目标主机防火墙可能拦截了探测包，尝试增大超时时间或减少线程数

### Q4: 大网段扫描卡顿或内存溢出
**解决**: 本工具内置任务量上限（100,000 个任务），超大网段建议分段扫描

### Q5: 导出文件时提示 "文件已存在"
**解决**: 这是安全设计，防止误覆盖。选择其他路径或删除旧文件后重试

### Q6: 如何修改默认常用端口？
**解决**: 编辑 `config.py` 中的 `COMMON_PORTS` 字典，重启程序生效

## 十、技术栈与架构

| 层级 | 模块 | 技术 | 设计原则 |
|------|------|------|---------|
| 数据层 | models.py | dataclass(frozen=True) | 不可变数据契约，线程安全 |
| 解析层 | ip_parser.py / port_parser.py | ipaddress, socket, re | 纯函数，零副作用 |
| 扫描层 | scanner.py / syn_scanner.py | socket, struct, ctypes | 异常内部消化，权限自动降级 |
| 调度层 | thread_manager.py | threading, queue | 线程池复用，支持暂停/恢复/停止 |
| 导出层 | exporters.py | csv, json | 策略模式，新增格式零侵入 |
| 配置层 | config_manager.py | os, json | 与 GUI 解耦，独立可测试 |
| 界面层 | main_window.py | PyQt6 | 零业务逻辑，信号驱动 |
| 入口层 | main.py | argparse | CLI/GUI 双模式统一入口 |
