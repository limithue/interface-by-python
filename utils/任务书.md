## 二、代码生成总体目标

基于原始 `exporter.py` 及问题分析中列出的 10 项缺陷，生成升级后的可直接运行源码，满足以下核心指标：

1. **零第三方依赖**：仅使用 Python 3.6+ 内置模块（`logging`、`logging.handlers`、`queue`、`threading`、`atexit`、`dataclasses`、`os`、`typing`）
2. **低耦合**：彻底废弃原 `config.py` 全局变量硬编码，配置由调用方注入，模块不感知外部配置来源
3. **高内聚**：日志注册、组装、调度、关闭全生命周期收敛于单一管理器类
4. **线程安全**：双检锁单例，多线程并发调用无重复 Handler、无竞态条件
5. **日志完整性优先**：高并发场景采用阻塞兜底异步队列，禁止丢弃日志
6. **优雅关闭**：进程退出或主动调用时，确保最后几条日志 flush/close 落盘

## 三、逐模块生成指令

### 模块一：LogConfig（配置实体层）

#### 3.1.1 生成指令
生成日志配置数据类，职责为聚合全部日志参数，作为调用方与日志模块之间的唯一契约接口。禁止包含任何业务逻辑或 I/O 操作。

#### 3.1.2 必须包含的字段

| 字段名 | 类型 | 默认值 | 规格说明 |
|--------|------|--------|----------|
| `level` | `int` | `logging.INFO` | 全局日志级别 |
| `console_level` | `int` | `logging.INFO` | 控制台 Handler 级别 |
| `file_level` | `int` | `logging.DEBUG` | 文件 Handler 级别 |
| `log_dir` | `str` | `"./output"` | 日志输出目录 |
| `log_file` | `str` | `"scanner.log"` | 日志文件名 |
| `max_bytes` | `int` | `10 * 1024 * 1024` | 单文件大小阈值，10MB |
| `backup_count` | `int` | `5` | 历史日志保留份数，超出自动删除最旧 |
| `datefmt` | `str` | `"%Y-%m-%d %H:%M:%S"` | 时间格式化字符串 |
| `fmt` | `str` | 含 `asctime`、`levelname`、`name`、`message` | 日志输出格式 |
| `queue_max_size` | `int` | `1000` | 异步队列最大缓冲条数 |
| `use_queue` | `bool` | `True` | 是否启用异步队列模式 |
| `encoding` | `str` | `"utf-8"` | 文件编码 |

#### 3.1.3 约束条件
- 必须使用 `@dataclass` 装饰器
- 所有字段必须有默认值，确保调用方零参数实例化即可使用
- 不得包含任何方法定义（除 dataclass 自动生成外）
- 不得导入或引用任何外部 `config` 模块

### 模块二：LoggerManager（核心管理器层）

#### 3.2.1 生成指令
生成日志生命周期管理器类，职责为提供命名 logger 的注册、Handler 组装、异步队列调度、优雅关闭。必须保证线程安全、单例防重复、模块级隔离。

#### 3.2.2 必须实现的类方法与属性

| 名称 | 类型 | 功能规格 | 异常处理要求 |
|------|------|----------|--------------|
| `_logger_registry` | 类属性 `Dict[str, Logger]` | 缓存已创建的命名 logger | 无 |
| `_listener_registry` | 类属性 `Dict[str, QueueListener]` | 缓存异步队列监听器 | 无 |
| `_registry_lock` | 类属性 `threading.Lock` | 双检锁线程安全 | 无 |
| `get_logger(name, config)` | 类方法 | 获取/创建模块级 logger，单例防重复 | 无异常抛出，内部消化 |
| `_assemble(name, cfg)` | 类方法（私有） | 组装 Formatter、Handlers、可选异步队列 | 无异常 |
| `_shutdown_one(name)` | 类方法（私有） | 停止 listener、flush/close handlers | 静默捕获所有异常 |
| `shutdown_all()` | 类方法 | 全局关闭所有注册 logger | 遍历调用 `_shutdown_one` |

#### 3.2.3 详细规格

**`get_logger` 方法**
- 参数 `name`：logger 名称，强烈建议使用 `__name__` 实现模块级隔离
- 参数 `config`：可选 `LogConfig` 实例，为 `None` 时使用默认配置
- 先检查 `_logger_registry`，命中则直接返回
- 未命中则获取 `_registry_lock`，再次检查（双检锁）
- 调用 `_assemble` 组装后存入注册表并返回

**`_assemble` 方法**
- 使用 `logging.getLogger(name)` 获取命名 logger，**禁止**使用 `logging.getLogger()` 获取 root
- 设置 `logger.setLevel(cfg.level)`
- 若 `logger.handlers` 非空，先遍历清空（防重复进入）
- 使用 `os.makedirs(cfg.log_dir, exist_ok=True)` 级联创建目录
- 组装 `Formatter`（使用 `cfg.fmt` 与 `cfg.datefmt`）
- 创建 `StreamHandler`，设置 `cfg.console_level`
- 创建 `RotatingFileHandler`（`maxBytes=cfg.max_bytes`，`backupCount=cfg.backup_count`），设置 `cfg.file_level`
- 若 `cfg.use_queue` 为 `True`：
  - 创建 `queue.Queue(maxsize=cfg.queue_max_size)`
  - 创建 `QueueHandler` 加入 logger
  - 创建 `QueueListener`，传入队列与实际 Handlers
  - 启动 listener，存入 `_listener_registry`
  - 注册 `atexit` 回调 `_shutdown_one(name)`
- 否则：直接将 Handlers 加入 logger
- 设置 `logger.propagate = False`，阻断向 root 传播

**`_shutdown_one` 方法**
- 从 `_listener_registry` 弹出并 `stop()` listener
- 从 `_logger_registry` 弹出 logger，遍历其 handlers
- 对每个 handler 执行 `flush()`、`close()`，静默捕获异常
- 移除 handler

**`shutdown_all` 方法**
- 遍历 `_listener_registry` 所有键，逐个调用 `_shutdown_one`

#### 3.2.4 关键约束
- 禁止裸 `except:`，必须捕获 `Exception` 并静默处理
- 禁止直接操作 root logger
- 必须使用 `RotatingFileHandler` 实现按大小轮转
- 异步队列满时必须阻塞（`QueueHandler` 默认行为），禁止设置非阻塞或丢弃策略
- 模块级文件末尾必须注册 `atexit.register(LoggerManager.shutdown_all)`

## 四、技术约束与规范

### 4.1 语言与环境约束
- Python 3.6+
- 零第三方库
- 仅使用白名单内置模块：`logging`、`logging.handlers`、`queue`、`threading`、`atexit`、`dataclasses`、`os`、`typing`

### 4.2 代码风格约束
- 函数/变量：小写 + 下划线
- 类：大驼峰
- 常量：全大写
- 必须加 docstring 与注释，说明修复的缺陷编号
- 类型注解完整

### 4.3 架构约束
- **低耦合**：不导入、不引用、不依赖任何外部 `config.py` 或全局变量
- **高内聚**：`LogConfig` 仅负责数据聚合；`LoggerManager` 仅负责生命周期管理；二者不泄露职责
- 调用方自行决定配置来源（环境变量、配置文件、命令行参数等），实例化 `LogConfig` 后注入

## 五、质量标准

### 5.1 功能质量
- 导入无异常
- 连续调用 `get_logger("test")` 3 次，Handler 不重复
- 两个不同 `name` 的 logger 互不干扰
- 写入 15MB 日志后，自动轮转生成 `.log.1` ~ `.log.5`，无 `.log.6`
- 删除原 `config.py` 后，模块仍可独立运行（使用 `LogConfig` 默认值）
- 程序退出时最后几条日志完整落盘

### 5.2 性能质量
- 高并发（1000 线程）写日志时，队列满阻塞但不丢失
- 异步模式下扫描线程不被磁盘 IO 阻塞
- 内存占用可控（队列缓冲上限 1000 条）

### 5.3 代码质量
- 无裸 `except:`
- 无死代码
- 无魔法数（配置参数收敛于 `LogConfig`）
- 线程安全（双检锁）
- 套接字无关（本模块不涉及网络套接字）
