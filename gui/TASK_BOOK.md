## 二、核心任务目标

1. **彻底修复原始代码缺陷**：消除运行时崩溃、类型不一致、线程控制失效等致命问题。

## 三、AI 需完成的具体任务

### （一）代码解析任务

1. **逐模块解读职责**：
   - `models` 层：`ScanResult` 数据契约、`ScanConfig` 配置对象、`PortState` 枚举状态。
   - `parsers` 层：`IPParser` 域名/IP/段解析、`PortParser` common/单端口/段解析。
   - `scanner` 层：`PortScanner` socket 探测、服务识别、Banner 抓取、ICMP/TCP 存活检测。
   - `thread_mgr` 层：`ThreadManager` 自定义线程池、任务队列、暂停/恢复/停止控制。
   - `exporters` 层：`IExporter` 抽象接口、`TxtExporter`、`CsvExporter`、`JsonExporter`、注册中心。
   - `worker` 层：`ScanWorker` QThread 工作线程、信号转发、统计聚合。
   - `gui` 层：`MainWindow` 界面布局、事件绑定、状态管理、关闭保护。

2. **解释核心逻辑**：
   - `scan_single` 统一返回 `ScanResult`，消除元组/字典混用。
   - `_worker_loop` 条件变量实现真正暂停/恢复，异常安全保证进度不丢失。
   - `ExporterRegistry` 策略模式实现导出格式零侵入扩展。
   - `ping_host` 权限异常捕获与 TCP 降级探测机制。

3. **说明执行流程**：
   输入 → 解析 → ICMP 预检（降级）→ 任务队列流式填充 → 并发扫描（随机延迟）→ 结果入队 → GUI 轮询 → 表格着色展示 → 日志输出 → 导出文件。

4. **标注关键函数**：
   - `PortScanner.scan_single()`：统一扫描入口，异常内部消化。
   - `PortScanner.ping_host()`：存活检测，含权限降级。
   - `ThreadManager._worker_loop()`：工作线程主循环，含条件变量挂起。
   - `ScanWorker.run()`：QThread 主循环，轮询结果队列并转发 PyQt 信号。
   - `MainWindow.toggle_pause()`：暂停/恢复状态机。
   - `ExporterRegistry.export()`：策略分发，格式无关调用。

### （二）功能实现任务

1. **整合代码**：输出可直接运行的单文件源码，无导入错误，PyQt6 为唯一第三方依赖。

2. **输入解析**：
   - 支持域名解析、单 IP、IP 段（`192.168.1.10-20`）、逗号分隔混合输入。
   - 支持 `common` 端口、单端口、端口段（`1-1000`）、逗号分隔混合输入。

3. **扫描核心**：
   - TCP 端口开放检测（`socket.create_connection` + Banner `recv`）。
   - UDP 端口开放检测（`SOCK_DGRAM` + `sendto/recvfrom`，无响应保守标记 OPEN）。
   - IP 存活预检（ICMP ping，无权限降级 TCP 探测）。
   - 自动匹配端口服务名称（`socket.getservbyport` + 回退映射表）。

4. **并发控制**：
   - 自定义线程池（`threading + queue`），最大线程 20。
   - 每任务随机延迟（0 ~ N 秒），降低防火墙拦截概率。
   - 结果通过 `queue.Queue` 线程安全传递，进度统计加锁保护。

5. **异常处理**：
   - 解析失败：弹出 QMessageBox 参数错误提示。
   - 端口格式错误：同上，明确提示非法字符或越界。
   - 无存活 IP：日志提示 `[WARN] 无有效扫描任务`，正常结束。
   - 扫描中异常：包装为 `PortState.ERROR`，不崩线程。

### （三）优化与增强任务

1. **架构优化**：
   - 按职责拆分为 7 个抽象层，层间通过接口/数据契约交互。
   - `ScanWorker` 依赖注入 `PortScanner` 与 `ThreadManager`，支持 Mock 测试。
   - 导出器注册中心模式，新增格式无需修改 GUI。

2. **线程调度优化**：
   - 条件变量 `_pause_cond` 实现真正暂停/恢复，非空转轮询。
   - `_stopped` 标志 + 队列清空实现秒级响应停止。
   - `try/finally` 保证异常任务也计入 `_processed`，进度不丢失。

3. **权限兼容**：
   - Windows 普通用户无管理员权限时，ICMP 抛 `PermissionError` 自动降级 TCP 探测。
   - 降级后 `_icmp_available = False`，后续所有主机跳过 ICMP，直接 TCP 预检。

4. **隐蔽性增强**：
   - 每任务随机延迟（`random.uniform(delay_min, delay_max)`）。
   - 线程上限锁定 20，避免并发过高触发防火墙规则。

5. **鲁棒性增强**：
   - 输入校验前置（解析失败不启动线程，避免资源浪费）。
   - 超时控制（socket 超时、ping 超时、线程 join 超时）。
   - 窗口关闭保护（扫描中关闭需二次确认，优雅 stop + wait）。

6. **UI 体验增强**：
   - 结果表格按状态着色（OPEN=绿、ERROR=红、FILTERED=黄、CLOSED=白）。
   - 日志带 `%H:%M:%S` 时间戳，Consolas 等宽字体。
   - 状态栏实时显示「总任务 / 已完成 / 开放端口」三指标。
   - 进度条百分比格式，完成强制置 100%，越界保护。

## 五、技术要求与约束

1. **语言**：Python 3.10+，无第三方库依赖，仅用内置模块 + PyQt6。
2. **协议**：TCP 扫描为主，ICMP 存活检测，UDP 可选实现。
3. **线程**：最大 20 线程（`AppConfig.MAX_THREADS = 20`），分批启动，带线程锁安全写入。
4. **权限**：Windows 需提示管理员权限（ICMP），无权限可降级运行（TCP 探测）。
5. **GUI 框架**：PyQt6，支持暂停/恢复/停止/导出/清空，结果表格实时着色。
6. **数据格式**：导出支持 TXT、CSV、JSON，通过注册中心扩展，零侵入 GUI。
7. **合规**：**严禁用于未授权网络**，仅限内网授权使用，源码顶部与界面均须体现声明。

## 七、风险与应对要求

| 风险场景 | 应对措施 | 实现位置 |
|----------|----------|----------|
| **无管理员权限** | ICMP 抛 `PermissionError` 时自动降级 TCP 探测，继续扫描 | `PortScanner.ping_host()` |
| **防火墙拦截** | 降低线程至 ≤20，增加随机延迟 0~N 秒，提升隐蔽性 | `ScanConfig.delay_max`, `ThreadManager._worker_loop()` |
| **IP 无法解析** | `socket.getaddrinfo` 预检，解析失败弹出 QMessageBox，不启动线程 | `IPParser.resolve_targets()` |
| **扫描过快被限制** | 固定最大线程数 20，每任务随机延迟，流式队列不一次性占满内存 | `AppConfig.MAX_THREADS`, `ThreadManager` |
| **超大网段卡死** | 任务流式分发至队列，不预加载全部结果至内存；建议追加 10 万任务上限校验 | `ScanWorker.run()` 任务构建 |
| **窗口关闭线程残留** | 重写 `closeEvent`，拦截退出 → `worker.stop()` → `wait(2000)` | `MainWindow.closeEvent()` |
| **UDP 无响应误判** | UDP 扫描无响应保守标记 OPEN，日志提示不确定性 | `PortScanner._scan_udp()` |

## 八、AI 执行规范

1. **严格依据原始代码重构**：保留原有功能边界，不随意增删扫描协议或攻击功能。
2. **保持工具轻量化**：命令行与 GUI 并存（本次聚焦 GUI），不引入重型框架。
3. **不实现漏洞利用、暴力破解、攻击功能**：纯端口扫描与状态检测，无 payload 发送。
4. **所有输出内容正式清晰**：文档可直接用于作业 / 项目交付，代码可直接运行。
5. **遵循高内聚低耦合原则**：
   - 每个类只负责一个抽象层次（数据 / 解析 / 扫描 / 调度 / 导出 / 控制 / UI）。
   - 层间通过数据契约（`ScanResult`）交互，不直接操作对方内部状态。
   - GUI 层零业务逻辑，仅负责布局、绑定、展示、用户交互。
6. **类型安全优先**：消灭元组/字典混用，统一 `dataclass(frozen=True)` 数据契约。
